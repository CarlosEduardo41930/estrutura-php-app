## Como chamar cada um depois de subir no GitHub:

---

Com Node/NPX:

> **Bash:**
>npx github:CarlosEduardo41930/estrutura-php-app meu-projeto-php

---

No Windows sem Node (PowerShell):

> **PowerShell:**
>irm https://raw.githubusercontent.com/CarlosEduardo41930/estrutura-php-app/main/setup.ps1 | iex

---

No Linux / Git Bash sem Node (Bash):

> **Bash**
>curl -sL https://raw.githubusercontent.com/CarlosEduardo41930/estrutura-php-app/main/setup.sh | bash -s -- meu-projeto-php
